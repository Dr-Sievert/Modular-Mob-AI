## DailyDialog (via the roskoN/dailydialog mirror on Hugging Face)

- **file**: `text/data/raw/dailydialog.jsonl`
- **download URL**: https://huggingface.co/datasets/roskoN/dailydialog/resolve/main/{train,validation,test}.zip
- **source page**: https://huggingface.co/datasets/roskoN/dailydialog
- **license / terms (as stated on the source page)**: CC BY-NC-SA 4.0 as stated by the original authors (Li et al., IJCNLP 2017); non-commercial research use.
- **downloaded size**: 2.2 MB
- **utterances extracted**: 102,979
- **notes**: 13,118 dialogues with per-utterance dialogue-act (inform/question/directive/commissive) and emotion labels, both kept in `meta`. The original http://yanran.li/files/ijcnlp_dailydialog.zip is dead and the canonical HF repo li2017dailydialog/daily_dialog ships only a loading script, so this mirror of the untouched original .txt files is used.

## EmpatheticDialogues (Facebook AI / ParlAI)

- **file**: `text/data/raw/empatheticdialogues.jsonl`
- **download URL**: https://dl.fbaipublicfiles.com/parlai/empatheticdialogues/empatheticdialogues.tar.gz
- **source page**: https://github.com/facebookresearch/EmpatheticDialogues
- **license / terms (as stated on the source page)**: CC BY-NC 4.0 per the facebookresearch/EmpatheticDialogues repository; non-commercial research use.
- **downloaded size**: 26.7 MB
- **utterances extracted**: 99,646
- **notes**: ~25k crowdsourced conversations grounded in one of 32 emotion labels; the emotion (`context` column) is kept in `meta`. `_comma_` placeholders in the CSV are restored to real commas.

## Cornell Movie-Dialogs Corpus (ConvoKit movie-corpus release)

- **file**: `text/data/raw/cornell_movie.jsonl`
- **download URL**: https://zissou.infosci.cornell.edu/convokit/datasets/movie-corpus/movie-corpus.zip
- **source page**: https://convokit.cornell.edu/documentation/movie.html
- **license / terms (as stated on the source page)**: Free for research use with citation of Danescu-Niculescu-Mizil & Lee (2011); the underlying movie scripts remain the property of their authors.
- **downloaded size**: 39.0 MB
- **utterances extracted**: 304,446
- **notes**: ~305k utterances from ~617 films. Fictional, dramatic and skewed towards conflict, which is useful for THREAT/INSULT/ACCUSE coverage. Streamed out of the zip line by line. The original cs.cornell.edu zip fails TLS verification from this machine, hence the ConvoKit mirror.

## Minecraft Server Chat (declip/Minecraft-Server-Chat)

- **file**: `text/data/raw/minecraft_chat.jsonl`
- **download URL**: https://huggingface.co/datasets/declip/Minecraft-Server-Chat/resolve/main/clean.json
- **source page**: https://huggingface.co/datasets/declip/Minecraft-Server-Chat
- **license / terms (as stated on the source page)**: CC0-1.0 (public domain dedication) as stated on the dataset card.
- **downloaded size**: 12.0 MB (truncated prefix, see notes)
- **utterances extracted**: 97,248
- **notes**: Real public Minecraft server chat: exactly the register the classifier will see in game (very short, typo-heavy, domain vocabulary). The full file is 342 MB, so only the first 12 MB are streamed and the complete records in that prefix are parsed. Usernames are dropped; only `content` is kept. Caveat: unmoderated player chat, so it contains profanity and noise - the filters in build_corpus.py remove some but not all of it.
